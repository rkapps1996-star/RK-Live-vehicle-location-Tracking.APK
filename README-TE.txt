Netlifyలో Live Tracking ప్రారంభించడానికి:
1) ఈ ఫోల్డర్‌లోని ఫైళ్లను మీ livetrackingrk.netlify.app సైట్ rootలో upload/deploy చేయండి.
2) ముఖ్యంగా viewer.html, app.js, index.html, styles.css తప్పనిసరిగా deploy కావాలి.
3) Supabaseలో public.live_locations table మరియు Realtime SQL మీరు ఇప్పటికే Run చేశారు.
4) యాప్‌లో GPS Start చేసి WhatsApp Share నొక్కండి. వచ్చిన viewer.html?id=... లింక్ ఇతర ఫోన్‌లో తెరిచి చూడండి.
